# Character acceptance

- The turnaround contains north, east, south, and west.
- Every animation contains all four directions.
- Identity, markings, accessories, proportions, and handedness remain stable.
- Each animation uses a consistent frame count and timing across directions.
- Contact points stay locked to the declared anchor.
- Motion reads correctly at native size without blur or interpolation.
- The north-west light remains fixed as the character turns.
- PNG dimensions match the manifest.
- The manifest uses `apartment-hotel-v1` or the documented neutral `apartment-fixtures-v2` palette for the rigged cat revisions.
- Source art, motion previews, and an in-room preview are retained.
