# Shop language

Shop connects customer artwork and product configuration to checkout, rendering and fulfilment. Its release vocabulary describes the versions and evidence required to keep those journeys working together.

## Products and fulfilment

**Configured product**:
A saved product configuration that binds an artwork revision to a garment, colour and placement.

**Print asset job**:
Work that prepares the geometry-specific artwork needed to print a configured product.

**Fulfilment lock**:
The point at which a paid order's validated delivery address, lines and artwork identities are committed for production.

## Releases

**Release composition**:
The selected component artifacts, compatibility contracts, target configuration and qualification evidence for one release. Each component retains its own source identity.

**Accepted work**:
A durably recorded customer operation or processing job whose ownership and processing contract remain valid while component versions change.

**Verified release**:
A release whose required provider observations and customer-journey checks agree with its admitted composition. Reporting delivery has a separate recorded outcome.

**Rollback**:
Selection of a previously verified, compatible code composition while preserving the current customer and order records.
