# Logo

`logo.png` is the original transparent 200px artwork used to create the favicon,
restored from commit `66c78a6` at
`apps/web/public/design-previews/favicon-user-v1.png`.

The social-card renderer swaps cobalt `#0647ff` and white `#ffffff` while
preserving the source geometry and transparency. This makes the outer shirt
white against the card's cobalt background.
